# Third-party notices and redistribution

Northpass is independent of Flowseal, Zapret, WinDivert and Cygwin. The consumer engine uses reviewed Flowseal-derived bytes pinned in `engine/catalog/flowseal.json`; the native v0.1 preview independently acquires the same official WinDivert x64 runtime from its pinned SDK in `native/windivert.json`. Native binaries include full WinDivert licence/README and corresponding source; upstream scripts are excluded from the executable payload and never run. Notices are shipped in `docs/licenses`; corresponding sources in `docs/third-party-source` use immutable URLs/hashes in `engine/catalog/redistribution-sources.json` and accompany the one-file offline installer. Historical licences for removed components are retained as provenance records; no Zapret2 or Lua runtime is included in the v0.6 product.

No project-wide licence for the original Northpass code has been selected; the repository owner must choose one before a public release. The requested development artifacts are unsigned and are not an authenticated release. See `docs/WINDOWS_ACCEPTANCE.md` before distribution.
