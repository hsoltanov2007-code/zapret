# Northpass — Zapret2 Engine Adapter (v0.1)

Независимое Windows-приложение (C# / WPF) с отдельным адаптером к внешнему движку Zapret2. **Не официальный продукт Zapret2.** Northpass — временное название.

> Это стартовый исходный проект, а не готовый обходчик «одной кнопкой». Профиль без аргументов намеренно не запускается; нужны официальный Windows-бандл и рабочая стратегия для конкретного провайдера.

## Что готово

- Собственный тёмный интерфейс Windows и управление запуском/остановкой;
- выбор `winws2.exe` и сохранение пути в `%LOCALAPPDATA%\Northpass\settings.json`;
- загрузка стратегий из отдельных JSON-файлов;
- безопасная передача аргументов через `ProcessStartInfo.ArgumentList` (без `cmd /c`);
- журнал stdout/stderr и выходного кода процесса;
- отдельный `IEngineAdapter` для будущего собственного движка;
- приложение запрашивает права администратора, необходимые WinDivert.

## Требования

- Windows 10/11 x64;
- .NET 8 SDK (для сборки, https://dotnet.microsoft.com/download/dotnet/8.0);
- официальный Windows bundle [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle) с `winws2.exe`, `cygwin1.dll`, `WinDivert.dll`, `WinDivert64.sys` и необходимыми файлами;
- соответствующий вашему провайдеру профиль. Zapret2 не гарантирует обход каждого способа блокировки.

## Запуск

1. Распакуйте архив и откройте PowerShell в корне проекта.
2. Выполните `powershell -ExecutionPolicy Bypass -File .\scripts\run-dev.ps1` или откройте `src/Northpass/Northpass.csproj` в Visual Studio 2022.
3. Укажите путь к **официальному** `winws2.exe`. Не переносите один EXE отдельно от зависимостей.
4. Отредактируйте `profiles/example-template.json`. В массив `Arguments` занесите отдельными строками **один аргумент на элемент** из своего проверенного профиля **Zapret2**. Не используйте старые флаги Zapret1 (`--dpi-desync=`). Для ссылок на файлы можно использовать `{ENGINE_DIR}` или `{PROFILE_DIR}`.
5. Нажмите «Обновить» и «Включить». По умолчанию пустые аргументы блокируют запуск.

## Сборка Windows EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Результат: `dist/Northpass/Northpass.exe`. Это собственное приложение, **не** комплектный Zapret2. Движок скачивается вручную из официального источника и запускается как отдельный процесс.

## Файловая структура

```text
src/Northpass/
  App.xaml, MainWindow.xaml       - интерфейс
  Models/                         - данные и профили
  Services/IEngineAdapter.cs      - универсальный контракт
  Services/Zapret2EngineAdapter.cs- временный движок
  Services/NativeEngineAdapter.cs - место для движка этапа 2
profiles/example-template.json    - шаблон аргументов
scripts/                         - запуск и публикация
engine/                          - место для официального комплекта
```

## План развития

- **0.2**: валидатор стратегий, удобный редактор, автопроверка нужных файлов;
- **0.3**: тесты соединений и журнал диагностики без обещаний универсальной работоспособности;
- **0.4**: tray, автостарт и контролируемая работа в фоне;
- **1.0**: установщик, обновления, подпись релизов;
- **2.0**: собственный движок за тем же `IEngineAdapter` без переписывания UI.

## Безопасность и лицензии

- Программа стартует с правами администратора. Используйте только доверенные файлы движка и стратегии.
- Не отключайте антивирус ради установки. Проверяйте источник и подписи/хеши скачанных файлов.
- Архив не содержит Zapret2, WinDivert или других сторонних бинарников.
- Самостоятельно сохраняйте копию лицензии MIT и уведомления авторов при распространении Zapret2; WinDivert и другие компоненты имеют свои условия. См. `THIRD_PARTY_NOTICES.md`.
- Отключение приложения завершает принадлежащий ему процесс winws2. Если отдельный winws2 запущен другим способом, Northpass его не контролирует.
